# 📊 Super Store Sales Dashboard | Power BI

An interactive retail sales analytics dashboard built using Microsoft Power BI to analyze sales performance, profitability, customer segments, product categories, regional trends, and shipping operations.

## 📌 Project Overview

The Super Store Sales Dashboard transforms raw retail transaction data into meaningful business insights through interactive visualizations and key performance indicators (KPIs).

The dashboard enables users to monitor business performance, identify sales trends, understand customer purchasing behavior, and evaluate product and regional performance to support data-driven decision-making.

## 🎯 Project Objectives

* Analyze overall sales, quantity sold, and profitability.
* Monitor key business performance indicators.
* Identify high-performing product categories and sub-categories.
* Understand customer segments and payment preferences.
* Analyze regional sales performance across states.
* Evaluate shipping methods and delivery timelines.
* Track monthly sales and profit trends over time.

## 🚀 Key Features

### 1. Executive KPI Tracking

The dashboard highlights four important business metrics:

| KPI                   |  Value |
| --------------------- | -----: |
| Total Sales           | $1.57M |
| Total Quantity Sold   |    22K |
| Total Profit          |  $175K |
| Average Delivery Time | 4 Days |

### 2. Monthly Sales Trend Analysis

* Visualizes monthly sales across 2019 and 2020.
* Helps identify seasonal patterns and sales fluctuations.
* Supports year-over-year performance comparisons.

### 3. Monthly Profit Analysis

* Tracks monthly profit across multiple years.
* Highlights changes in profitability.
* Helps identify periods of stronger or weaker financial performance.

### 4. Customer Segment Analysis

Analyzes sales distribution across three customer segments:

* Consumer — 48%
* Corporate — 33%
* Home Office — 19%

This analysis helps understand which customer groups contribute most to overall sales.

### 5. Payment Mode Analysis

Examines sales distribution across different payment methods:

* Cash on Delivery (COD)
* Cards
* Online payments

This helps identify customer payment preferences.

### 6. Product Category Analysis

Evaluates sales performance across the main retail categories:

* Furniture
* Office Supplies
* Technology

The dashboard also provides insights into product sub-categories, including Phones, Chairs, and Binders.

### 7. Geographic Sales Analysis

* Visualizes sales distribution across states.
* Helps identify high-performing geographic markets.
* Supports regional performance comparisons.

### 8. Shipping Mode Analysis

Analyzes sales across different shipping methods:

* Standard Class
* Second Class
* First Class
* Same Day

This provides an overview of order distribution across shipping options.

### 9. Interactive Regional Filtering

The dashboard includes regional slicers for:

* Central
* East
* South
* West

Users can select a region to filter dashboard visuals and explore specific business performance metrics.

## ▶️ How to Run the Project

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://www.microsoft.com/power-platform/products/power-bi/desktop).
3. Download the `.pbix` project file from this repository.
4. Open the file using Power BI Desktop.
5. Explore the dashboard using the available slicers and interactive visualizations.
